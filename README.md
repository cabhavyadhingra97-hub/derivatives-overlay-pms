# Derivatives Overlay Program
### Multi-Asset Hedging Program (Equity + Debt + FX) — ₹78 Cr PMS Mandate

**Author:** CA Bhavya Dhingra  
**Type:** Institutional Risk Overlay & Derivatives Design  

---

## Project Overview

Designed a four-instrument derivatives overlay for a 14-client, ₹78 Cr concentrated equity book **without disturbing any underlying holding**.

**Instruments used:**
- Equity collars and covered calls
- Interest-rate swap
- FX risk-reversal

---

## Key Outcomes

- **Net cash-flow-positive** program: 177.3 bps/yr covered-call income against 27.5 bps/yr hedging cost
- Modelled stress-drawdown reduction of **177–888 bps** across severity levels
- Built a **Black-Scholes-Merton pricing engine and Greeks calculator from first principles** in Python (no third-party pricing library)
- Caught a pre-submission blind spot — original protection-sleeve names were not NSE F&O-eligible — and screened in verified, currently optionable alternatives

## Core Design Constraint

The overlay had to deliver meaningful protection while remaining inside a hard cost budget and the explicit rule that **no underlying position could be sold**. The final structure achieved both protection and a net credit outcome.
